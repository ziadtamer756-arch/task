# إعداد القنوات في الإصدار 0.3

## Telegram Bot API

1. أنشئ بوتًا من BotFather في Telegram.
2. افتح «ربط واتساب وتليجرام» وأدخل رمز البوت في الحقل المخفي. استخدم «اختبار اتصال تليجرام» للتحقق من الهوية دون إرسال رسالة.
3. يبدأ المستلم المحادثة مع البوت، أو يُضاف البوت للمجموعة بصلاحية مناسبة. البوت لا يبدأ مراسلة شخص عشوائي من رقم هاتفه.
4. يمكنك إدخال Chat ID في جهات الاتصال أو استخدام «استيراد محادثات البوت الحديثة». هذا يقرأ التحديثات المتاحة للبوت فقط؛ لا يعرض كل محادثات حساب Telegram الشخصي. لا يغيّر webhook ولا يؤكد التحديثات بإرسال offset. وجود webhook أو عميل polling آخر قد يمنع هذه القراءة.
5. أنشئ حملة واختر «تليجرام»، ثم راجع المعاينة. النص يدعم متغيرات جهات الاتصال، بما فيها `{telegram_chat_id}`. التطبيق يدعم نصوص البوت حتى 4096 حرفًا، ولا يرفق ملفات عبر هذه القناة في هذا الإصدار.

هذه إضافة عبر Bot API، وليست استنساخًا لمدير جلسات حسابات Telegram الشخصية الظاهر في ملفات المرجع.

## WhatsApp Cloud API

1. تحتاج حساب WhatsApp Business معدًا لـ Cloud API مع Phone number ID ورمز وصول بصلاحياته المناسبة.
2. أدخل القيم في «ربط واتساب وتليجرام»، وحدد إصدار Graph API المدعوم لحسابك. القيمة الافتراضية `v23.0` قابلة للتغيير وليست ادعاءً بأنها أحدث إصدار.
3. زر اختبار الاتصال يقرأ بيانات رقم Business؛ لا يرسل رسالة.
4. سجّل أرقام المستلمين مع كود الدولة، مثل `+201001234567`.
5. لبدء الرسائل، اختر القالب المعتمد في حسابك، واكتب اسمه ورمز لغته وقيم متغيرات **نص القالب** بالترتيب، قيمة في كل سطر. القيم تدعم `{name}` و`{phone}` وبقية متغيرات التطبيق. عدد القيم وترتيبها يطابقان تعريف القالب لدى Meta. المعاينة تعرض الاسم واللغة والقيم، وليس نص القالب المعتمد الموجود لدى المزود.
6. خيار «نص داخل نافذة خدمة العميل» مستقل، ويحتاج نافذة تسمح بها الخدمة، عادةً خلال 24 ساعة من رسالة العميل. التطبيق لا يستطيع إثبات هذه النافذة محليًا؛ المزود يتحقق منها.

لا يدعم هذا الإصدار QR/WhatsApp Web، حسابات WhatsApp الشخصية، فحص وجود أرقام على WhatsApp، استخراج أعضاء المجموعات، مكونات قوالب الصور/الأزرار، أو استقبال Webhooks للتسليم والقراءة.

## النتائج والبيانات

- `preview`: محاكاة محلية؛ لا تُجرى طلبات إرسال أو تحقق هوية.
- `accepted`: رجع معرّف رسالة من المزود؛ لا يثبت الوصول أو القراءة.
- `held`: وضع WhatsApp الرسالة قيد مراجعة الجودة؛ إرسالها غير مؤكد.
- `failed`: فشل محدد أو نتيجة غير مؤكدة. أخطاء الخدمة تُعرض دون نص الاستجابة الخام أو رموز الدخول.
- `paused`: أوقفت الحملة بقية المستلمين بسبب المصادقة أو حد الإرسال. لا تُجرى إعادة محاولة تلقائية.
- يُحفظ وضع `running` قبل أول طلب شبكة. لو توقف التطبيق، يظهر السجل `interrupted` ولا يعاد الإرسال تلقائيًا.
- إلغاء الاشتراك يطبق على نفس عنوان القناة عبر جميع المجموعات. تُحفظ معرّفات الرسائل في تقارير الحملة.

رموز Telegram وWhatsApp وكلمة مرور SMTP تبقى في الذاكرة، وتُدخل مجددًا عند فتح التطبيق. أسماء الحسابات وإعداداتها غير السرية وقوائم الجمهور والنتائج تُحفظ محليًا في ملف JSON. لا ترسل الرموز السرية في المحادثة.

الوصول إلى `api.telegram.org` و`graph.facebook.com` مطلوب من جهاز Windows. هذه الوجهات ليست مطلوبة للاختبارات الآلية التي تستخدم HTTP بديلًا. لم تُختبر بيانات حساب إنتاجي أو إرسال إلى مستلم حقيقي في بيئة التطوير.
