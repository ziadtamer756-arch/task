# النسخة الجديدة من Sender Pro

هذا تنفيذ مستقل لبرنامج Windows بالعربية. ليست نسخة مكتملة أو مطابقة بصريًا للبرنامج الأصلي، ولا تحتوي على المكتبات التجارية المرفوعة أو نظام تفعيل البرنامج الأصلي.

## المنفذ حاليًا

- واجهة Windows Forms عربية مع قائمة جانبية، حالة القسم النشط، بطاقات إحصاءات وجداول موحدة. التخطيط يتكيف مع عرض النافذة بدل العروض الثابتة.
- دعم PerMonitorV2 لقياس الواجهة على الشاشات ذات DPI مختلف.
- جهات اتصال قابلة للتعديل والبحث والحذف، مع مجموعات وحالة إلغاء الاشتراك.
- استيراد وتصدير CSV، مع دعم الاقتباسات والعربية والأسطر المتعددة ومنع تكرار البريد أو الهاتف أثناء الاستيراد.
- استيراد وتصدير XLSX مع حفظ الهاتف كنص والحفاظ على الأعمدة عند وجود خلايا فارغة.
- قوالب ورسائل مخصصة بالاسم والبريد والهاتف والمجموعة ومعرّف محادثة تليجرام.
- مكتبة محتوى قابلة للبحث بالاسم والنص والوسوم، مع استيراد عدة ملفات TXT وربط الوسائط ومراجعة الملفات المفقودة. يمكن تطبيق النص على كل القنوات وإرفاق الملفات بالبريد.
- حملات نصية عبر Telegram Bot API، وقوالب نصية معتمدة أو نص نافذة الخدمة عبر WhatsApp Cloud API. رموز الدخول في الذاكرة فقط، مع اختبار اتصال واستيراد محادثات البوت الحديثة. راجع [إعداد القنوات](messaging-setup.md).
- حملات بريد لمجموعة أو لكل جهات الاتصال، معاينة دون إرسال وإرسال SMTP فعلي.
- معاينة حية لعنوان الرسالة ونصها لأول جهة اتصال في المجموعة، مع إضافة وحذف مرفقات البريد.
- إيقاف حملة أثناء التنفيذ، وتسجيل النجاح والفشل والاستبعاد؛ منع إعادة إرسال سجل حملة سابق.
- تقارير محفوظة وتصدير CSV.
- إعدادات STARTTLS/SMTP وكلمة مرور في الذاكرة فقط.
- شاشة تعرض قنوات التواصل وحالة تنفيذ كل قناة. البريد وTelegram Bot API وWhatsApp Cloud API مدمجة؛ بقية التكاملات غير منفذة. أسماء 351 ملفًا مرجعيًا محفوظة في وثائق المشروع ولا تُعرض كأزرار وظائف.
- حفظ JSON محليًا ونسخة احتياطية قبل استبدال الملف. إذا تلفت البيانات، تظهر رسالة خطأ ولا تُستبدل بصمت. الحملات التي توقف فيها البرنامج تُعرض interrupted دون إعادة إرسال تلقائي.

## التشغيل على Windows

استخدم Windows 10/11 بمعمارية x64. فك ضغط حزمة الإصدار ثم شغّل `SenderPro.exe` من داخل المجلد. الحزمة self-contained تشمل runtime ولا تحتاج تثبيت .NET. احتفظ بملف `feature-catalog.json` وباقي ملفات الحزمة مع البرنامج.

البيانات في `%LOCALAPPDATA%\SenderProCommunity\data.json` والنسخة الاحتياطية `data.json.bak`. لا تُحفظ كلمة مرور SMTP. يتطلب الإرسال خادمًا صالحًا وبيانات حسابك، ويمكن تجربة الاستيراد والمعاينة محليًا دون حساب. إلغاء الاشتراك موجود في قائمة جهات الاتصال محليًا، وليس خدمة روابط إلغاء اشتراك مستضافة.

يدعم النقل STARTTLS على 587 أو خادمًا بدون TLS حسب إعداد المستخدم. TLS الضمني على 465 غير مدعوم. قبول خادم SMTP للرسالة لا يثبت وصولها أو قراءتها. لا يوجد إعادة محاولة تلقائية للرسائل الفاشلة لتجنب إرسال مكرر عند غموض نتيجة اتصال الخادم.

## البناء من المصدر

استخدم .NET SDK 8.0.425. من جذر المشروع:

```powershell
dotnet build src/SenderPro.Windows/SenderPro.Windows.csproj -c Release
dotnet run --project tests/SenderPro.Checks/SenderPro.Checks.csproj -c Release
dotnet publish src/SenderPro.Windows/SenderPro.Windows.csproj -c Release -r win-x64 --self-contained true -o artifacts/windows-x64
```

يمكن بناء الحزمة على Linux عبر EnableWindowsTargeting، لكن الواجهة نفسها لا تعمل على Linux. يفحص GitHub Actions صفحات Windows وحالات القنوات على ثلاثة أحجام نافذة، ويتحقق من تجاوز العرض داخل الحاويات، ويشغّل معاينة محلية لكل قناة. تُحفظ صور الشاشات ونتائج المعاينة ومحرر المكتبة وتقارير الفحص في SenderPro-Windows-UI. هذا فحص تشغيل وتخطيط، وليس اختبارًا شاملًا لتفاعل المستخدم أو مطابقة الشكل الأصلي. اختبارات منطق التطبيق تعمل على النظامين، وتشمل اتصال SMTP بخادم اختبار loopback لا يرسل رسائل خارج الجهاز. طلبات Telegram/WhatsApp تُختبر عبر HTTP بديل؛ الإرسال الإنتاجي لجميع القنوات يحتاج تحققًا منفصلًا ببيانات حساب صالح.

## المطلوب لاستكمال المطابقة

صور أو فيديو لكل شاشة وقائمة وإعداد، وترتيب أقسام الاستخدام. أسماء الملفات في PDB لا تكشف القيم الافتراضية، تفاصيل الأزرار أو السلوك الداخلي. لم يُسترجع كود المصدر الأصلي ولم يُشغل الملف الأصلي في هذه البيئة.

Facebook وInstagram وX وبقية المنصات غير مدمجة بعد. الربط الحالي لـ Telegram وWhatsApp يستخدم Bot API وCloud API، ولا يطابق بالضرورة مدير الجلسات أو أسلوب البرنامج الأصلي. تشمل الفجوات أيضًا الجدولة، SMS، تسجيل حسابات المنصات، والخدمات الخارجية. يجب تحديد واجهات الربط والمتطلبات لكل تكامل واختباره بحساب مناسب قبل وصفه بأنه يعمل. هذه الحزمة لا تدعي اكتمال جميع تفاصيل البرنامج الأصلي. ملف التصحيح المرفوع لا يطابق GUID ملف التشغيل؛ راجع [تحليل المرجع](reference-analysis.md) لتفريق ما ثبت من EXE وما هو مجرد أسماء في PDB.

## تغييرات الإصدار 0.2

التصميم الجديد، Excel، مرفقات البريد، المعاينة الحية، منع التكرار عند الإضافة اليدوية، عرض حالات الحملات بالعربية، التخلص من صفحات الواجهة السابقة عند التنقل، وفحص تشغيل الشاشات على Windows في CI. لا توجد مطالبة بأن هذه التغييرات تحقق تطابق كل وظائف البرنامج الأصلي.

## تغييرات الإصدار 0.3

اختيار قناة الحملة، حسابات البوت وBusiness، Chat ID اختياري في CSV/XLSX مع الحفاظ على الملفات القديمة، قوالب واتساب ومعرّفات رسائل المزود، استيراد محادثات البوت، ومكتبة المحتوى والوسوم والوسائط. أُصلح إلغاء الاشتراك عبر المجموعات، وحفظ بداية التنفيذ قبل الشبكة، وحجب بيانات الرموز من أخطاء HTTP. لم تُستخدم بيانات حساب إنتاجي في التحقق.
