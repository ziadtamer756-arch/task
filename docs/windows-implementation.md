# النسخة الجديدة من Sender Pro

هذه بداية تنفيذ مستقلة لبرنامج Windows بالعربية. ليست نسخة مكتملة أو مطابقة بصريًا للبرنامج الأصلي، ولا تحتوي على المكتبات التجارية المرفوعة أو نظام تفعيل البرنامج الأصلي.

## المنفذ حاليًا

- واجهة Windows Forms عربية مع قائمة جانبية، حالة القسم النشط، بطاقات إحصاءات وجداول موحدة. التخطيط يتكيف مع عرض النافذة بدل العروض الثابتة.
- دعم PerMonitorV2 لقياس الواجهة على الشاشات ذات DPI مختلف.
- جهات اتصال قابلة للتعديل والبحث والحذف، مع مجموعات وحالة إلغاء الاشتراك.
- استيراد وتصدير CSV، مع دعم الاقتباسات والعربية والأسطر المتعددة ومنع تكرار البريد أو الهاتف أثناء الاستيراد.
- استيراد وتصدير XLSX مع حفظ الهاتف كنص والحفاظ على الأعمدة عند وجود خلايا فارغة.
- قوالب ورسائل مخصصة بالاسم والبريد والهاتف والمجموعة.
- حملات بريد لمجموعة أو لكل جهات الاتصال، معاينة دون إرسال وإرسال SMTP فعلي.
- معاينة حية لعنوان الرسالة ونصها لأول جهة اتصال في المجموعة، مع إضافة وحذف مرفقات البريد.
- إيقاف حملة أثناء التنفيذ، وتسجيل النجاح والفشل والاستبعاد؛ منع إعادة إرسال سجل حملة سابق.
- تقارير محفوظة وتصدير CSV.
- إعدادات STARTTLS/SMTP وكلمة مرور في الذاكرة فقط.
- شاشة تعرض قنوات التواصل وحالة تنفيذ كل قناة. البريد متاح؛ بقية تكاملات المنصات غير منفذة. أسماء 351 ملفًا مرجعيًا محفوظة في وثائق المشروع ولا تُعرض كأزرار وظائف.
- حفظ JSON محليًا ونسخة احتياطية قبل استبدال الملف. إذا تلفت البيانات، تظهر رسالة خطأ ولا تُستبدل بصمت. الحملات التي توقف فيها البرنامج تُعرض interrupted دون إعادة إرسال تلقائي.

## التشغيل على Windows

استخدم Windows 10/11 بمعمارية x64. فك ضغط حزمة الإصدار ثم شغّل `SenderPro.exe` من داخل المجلد. الحزمة self-contained تشمل runtime ولا تحتاج تثبيت .NET. احتفظ بملف `feature-catalog.json` وباقي ملفات الحزمة مع البرنامج.

البيانات في `%LOCALAPPDATA%\SenderProCommunity\data.json` والنسخة الاحتياطية `data.json.bak`. لا تُحفظ كلمة مرور SMTP. يتطلب الإرسال خادمًا صالحًا وبيانات حسابك، ويمكن تجربة الاستيراد والمعاينة محليًا دون حساب. إلغاء الاشتراك موجود في قائمة جهات الاتصال محليًا، وليس خدمة روابط إلغاء اشتراك مستضافة.

يدعم النقل STARTTLS على 587 أو خادمًا بدون TLS حسب إعداد المستخدم. TLS الضمني على 465 غير مدعوم. قبول خادم SMTP للرسالة لا يثبت وصولها أو قراءتها. لا يوجد إعادة محاولة تلقائية للرسائل الفاشلة لتجنب إرسال مكرر عند غموض نتيجة اتصال الخادم.

## البناء من المصدر

استخدم .NET SDK 8.0.425. من جذر المشروع:

```powershell
dotnet build src/SenderPro.Windows/SenderPro.Windows.csproj -c Release
dotnet run --project tests/SenderPro.Checks/SenderPro.Checks.csproj -c Release
dotnet publish src/SenderPro.Windows/SenderPro.Windows.csproj -c Release -r win-x64 --self-contained true -o artifacts/windows-x64
```

يمكن بناء الحزمة على Linux عبر EnableWindowsTargeting، لكن الواجهة نفسها لا تعمل على Linux. يفحص GitHub Actions فتح الشاشات السبع على Windows بثلاثة أحجام نافذة، ويتحقق من عدم تجاوز عناصر الصفحة عرضها، ويحفظ 21 لقطة PNG وتقارير في SenderPro-Windows-UI. هذا فحص تشغيل وتخطيط، وليس اختبارًا شاملًا لتفاعل المستخدم أو مطابقة الشكل الأصلي. اختبارات منطق التطبيق تعمل على النظامين، وتشمل اتصال SMTP بخادم اختبار loopback لا يرسل رسائل خارج الجهاز. اتصال SMTP الإنتاجي يحتاج تحققًا منفصلًا ببيانات الخادم الحقيقي.

## المطلوب لاستكمال المطابقة

صور أو فيديو لكل شاشة وقائمة وإعداد، وترتيب أقسام الاستخدام. أسماء الملفات في PDB لا تكشف القيم الافتراضية، تفاصيل الأزرار أو السلوك الداخلي. لم يُسترجع كود المصدر الأصلي ولم يُشغل الملف الأصلي في هذه البيئة.

تكاملات WhatsApp وFacebook وInstagram وTelegram وX وباقي المنصات غير منفذة بعد. تشمل الفجوات أيضًا الجدولة، SMS، تسجيل حسابات المنصات، والخدمات الخارجية. يجب تحديد واجهات الربط والمتطلبات لكل تكامل واختباره بحساب مناسب قبل وصفه بأنه يعمل. هذه الحزمة تنفذ الأساس والبريد فقط ولا تدعي اكتمال جميع التفاصيل.
